# Ownership, licensing and IP decisions

HerPages is an owner-led commercial product concept. The repository being public does not by itself choose an open-source license. No MIT, Apache or other blanket license is added on the owner's behalf in this baseline. The owner should choose code/documentation licensing and contributor terms with appropriate advice before accepting external contributions or distributing a product.

The brand name and tagline reflect the user's selection, not a completed trademark/domain clearance. Conduct clearance in intended markets before material brand spend. Do not treat a GitHub repository name as a registered trademark.

Third-party libraries, fonts, icons, photographs, illustrations, training data and content need an inventory and compatible licenses. Record origin, version, license, permitted use, attribution and restrictions. Never bundle font files from a development environment without verified distribution rights. Use system fonts initially.

Competitor materials and public opportunity pages are sources, not a license to copy a database or interface. Respect source terms and use official APIs/manual curation until rights are established. No employer/client confidential data, user identities, child records or private conversation exports belong in this public repo.

AI-generated code still needs dependency, IP and security review. Tool access does not prove that every generated asset is exclusively ownable. Keep model/tool use and human review records where material.

Before launch, resolve legal entity, contributor assignment/permission, repository license, brand clearance, content licenses, user-content rights limited to service needs, and processor agreements. Avoid overly broad rights to exploit a girl's private story.
