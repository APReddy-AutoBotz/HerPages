# Delivery roadmap

## Plan by evidence, not the builder promotion

The full product vision remains in the repository. Bolt's temporary allowance changes build capacity, not privacy requirements or launch readiness. The exact entitlement expiry is checked by the owner. Relative weeks below are planning hypotheses, not a delivery guarantee.

| Release | Goal | Required evidence | Main tasks |
|---|---|---|---|
| R0 | Complete architecture/requirements baseline | Documentation validator, reviewed assumptions, source register | HP-001 |
| R1 | Native offline private-page proof | Real device encryption, save/search, export/restore, stage/access boundary and large text | HP-002–006, HP-010, HP-024 |
| R2 | Trustworthy foundation beta | Auth/consent, audited backup/recovery, catalog, privacy rights and operational readiness | HP-007–012, HP-014–015, HP-020, HP-023 |
| R3 | Useful growth and program pilot | Research evidence, reviewed activities, local matching, bounded organization workflow | HP-013, HP-016, HP-022, HP-025 |
| R4 | Moderated adult connection | Adult eligibility, staffed moderation/reporting, mentor safeguards | HP-018–019 |
| R5 | Optional advanced capabilities | Separate AI, location and country approvals | HP-017, HP-021, further localization |

Parent-led real-child beta is a separate gate even if the R2 software is complete. Direct minor participation requires additional approval. No release number automatically enables a risky feature.

## First four-week acceleration tranche

**Week 1:** scaffold the standard repo; render tokens and lifecycle fixtures; prove native SQLCipher/secure-key/recovery feasibility; draft test harness. A web-only proof is insufficient. **Week 2:** local Pages/search/media/export with honest storage states and accessible UX. **Week 3:** catalog/editorial/partner mock flows and policy API contracts; start safe service skeleton only after privacy boundaries are fixed. **Week 4:** strengthen tests, docs and clean-room handover; build only the next coherent slice if gates are met.

Run customer research in parallel with adult participants. Do not spend the entire promotion generating disconnected screens. If the encryption spike fails, solve that before allowing real private content, while continuing safe catalog/design work.

## Codex continuation

Codex starts from the exact handover commit, checks task state and reproduces local/native tests. It completes backup, authority, operations and gated beta before pursuing community or AI breadth. Each tranche ends with evidence and updated status. No overnight autonomous deployment to production or real-child data import.

## Explicitly deferred

Unrestricted minor social networking; real-time multi-writer E2EE sync; production live location; direct police dispatch; clinical/financial decision tools; automatic job/scholarship application; public search of girls; insurer/healthcare integration; data monetization; ad targeting; every-country launch. These are not hidden backlog commitments.
